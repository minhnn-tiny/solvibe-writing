## Building the review manuscript

Run the following from the manuscript directory containing `main.tex`, `acmart.cls`, and `ACM-Reference-Format.bst`. This uses pdfLaTeX, BibTeX and latexmk, with the standard ACM fonts supplied by TeX Live. The resulting PDF is `build/main.pdf`.

```sh
latexmk -pdf -bibtex -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build main.tex
```

The generic upstream sample includes publication metadata placeholders and a tagged-PDF preamble targeting recent LuaLaTeX. The anonymous review draft uses the class options in the ISSTA instructions. A review-format smoke test with a BibTeX citation passed on the host's TeX Live 2022/dev. The resulting PDF had embedded fonts and anonymous author information.

An independent build of the unmodified upstream sample with LuaLaTeX on a user-space TeX Live 2026 installation reproduced the 11-page tagged layout with embedded fonts. The example emitted 16 missing-character messages and eight BibTeX warnings. The anonymous review smoke test resolved its citation and produced no missing-character messages.
