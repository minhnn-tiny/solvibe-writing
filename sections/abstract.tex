A maintainer receives an agent's patch for an audited Solidity defect. The regression example in the report now passes. What does that result establish for a caller who uses the contract through a different interface? In an archived study of one Angstrom finding, 96 patches passed the example supplied to the repair agent. Eighteen of those patches failed a second security check that was fixed before those patches were assessed. We use this observation to distinguish three questions. Does a patch restore the reported operation while preserving its specified ordinary use? Does it also restore a separately documented behaviour? Would showing the agent a different example change which behaviour it repairs? We report how far public findings support these measurements. By 26 November 2026 we had reviewed 225 external findings for scope. Of these, 54 cleared review, 53 compiled on both historical revisions, and 31 passed the specified ordinary-use tests offline on both. Only one finding had a page ready for human judgment. In one deferred case, the example distinguished the two historical revisions but could also signal the defect when the operation was refused for a different reason. We therefore examine what the example tells the agent and require private evidence that a patch preserves a permitted outcome. We describe a randomized comparison in which both illustrated behaviours are graded regardless of which example the agent receives. At the reporting cut no case had signed admission and no expanded-benchmark repair session had run. The causal effect of example choice remains open.
